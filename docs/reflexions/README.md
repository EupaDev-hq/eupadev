# Working notes (not published)

The ADRs and some READMEs cite files under `docs/reflexions/`: the
maintainer's working notes (research, design notes, measurements) written
while the project was private. They are not part of this repository.

What they led to is here: the decisions in [`docs/adr/`](../adr/), the
architecture in [`docs/architecture.md`](../architecture.md). Accepted ADRs
are immutable, so their source lines stay as written.

Need the reasoning behind a decision? Open an issue and name the ADR.
