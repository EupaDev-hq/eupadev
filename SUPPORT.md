# Support

EupaDev is maintained by one person, on a best-effort basis: there is no
guaranteed response time and no paid support.

- **Bug**: open an issue with the bug form.
- **Idea or feature request**: open an issue with the feature form;
  check [`ROADMAP.md`](ROADMAP.md) first.
- **Security vulnerability**: never in an issue — see
  [SECURITY.md](SECURITY.md).
- **Code of conduct**: admin@eupadev.org.
